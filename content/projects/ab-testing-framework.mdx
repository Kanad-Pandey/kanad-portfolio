## Solution

Developed a robust, multi-channel A/B testing framework:

- **HCP Randomization:** Implemented balanced randomization logic to ensure comparable test and control groups across therapeutic areas.
- **Bayesian Inference:** Leveraged Bayesian statistical models to provide real-time probability-to-win metrics for ongoing experiments.
- **Reporting:** Built automated Power BI dashboards to communicate experimental results and confidence intervals to executive leadership.

<CodeBlock 
  filename="ab_test_analyzer.py"
  language="python"
  code={`import scipy.stats as stats

def analyze_lift(control_sales, variant_sales):
    # Calculate statistical lift and p-value
    t_stat, p_val = stats.ttest_ind(variant_sales, control_sales)
    lift = (variant_sales.mean() - control_sales.mean()) / control_sales.mean()
    
    return {
        "lift": f"{lift:.2%}",
        "confidence": f"{1 - p_val:.2%}",
        "is_significant": p_val < 0.05
    }`}
