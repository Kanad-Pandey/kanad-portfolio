## Solution

Developed a comprehensive FinOps framework for Snowflake:

- **Utilization Tracking:** Built dashboards to monitor real-time warehouse compute and credits.
- **Attribution:** Implemented cost-attribution tagging to track spend by department and project.
- **Optimization:** Identified and decommissioned underutilized resources and optimized query performance.

## Impact

- **Transparency:** Provided leadership with clear visibility into cloud ROI.
- **Governance:** Established a sustainable framework for long-term cloud cost management.
- **Savings:** Identified significant cost-optimization opportunities through resource rightsizing.

## Tech Stack

- **Platform:** Snowflake
- **Analysis:** SQL, Python
- **Reporting:** Power BI
